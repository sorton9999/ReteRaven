bool ReteEngine.ReteEngineOptions.AutoRefreshOnPropertyChanged = true
get

Gets or sets whether the engine subscribes to INotifyPropertyChanged facts and refreshes the network automatically when those facts change. When disabled, callers must explicitly call Update or Refresh after a change. This setting does not prevent the fact object itself from being mutated.
