Detailed Description

Provides a shared base implementation for fluent aggregation builders (GroupBuilder<TInitial, TRightFact> and GroupByBuilder<TInitial, TRightFact, TKey>), centralizing strongly typed scalar aggregation operations (Count, Sum, Average, Min, Max) and type-erased IGroupAggregationShim<TInitial> adapters.

Template Parameters
TInitialThe initial fact type that started the rule chain.
TRightFactThe type of fact being collected and aggregated.
