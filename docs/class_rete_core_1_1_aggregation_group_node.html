Detailed Description

Represents a RETE network node that performs aggregation over groups of facts matching specified join conditions.

Aggregates right input facts for each left input token using a provided aggregation function, and propagates the aggregated result to successor nodes. Manages assertion, retraction, and refresh of facts while maintaining state for efficient incremental updates.
