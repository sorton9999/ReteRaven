Detailed Description

A interface for building group operations in a Rete network. It allows the user to define conditions for grouping facts and specify aggregation operations such as Sum, Count, and Average on the grouped data. The interface is generic and works with an initial fact type TInitial, while the specific type of facts being grouped is determined by the implementation.
