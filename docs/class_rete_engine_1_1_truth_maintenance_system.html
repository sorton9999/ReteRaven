Detailed Description

Manages event-driven logical justifications between rule match Tokens and logically asserted facts in working memory, supporting multi-justification reference counting and transitive cascade retractions.

Subscribes to ReteEngine.FactChangesPublished to record logical assertions and to TerminalNode.TokenRetracted to remove invalidated justifications. When a logically derived fact loses its final supporting justification, LogicalFactOrphaned is raised so the engine automatically retracts the orphaned fact from working memory without requiring manual cleanup rules.
