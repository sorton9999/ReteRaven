Detailed Description

A Rete network node that dynamically partitions incoming facts of type TRightFact into keyed buckets using _keySelector, incrementally computing an aggregate value per bucket and emitting one derived Token per non-empty group.

Template Parameters
TRightFactThe type of fact being partitioned and aggregated.
TKeyThe non-nullable type of the grouping key.
Type Constraints
TKey :notnull
