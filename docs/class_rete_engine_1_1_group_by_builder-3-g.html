Detailed Description

Configures and compiles a standalone GroupByNode<TRightFact, TKey> that partitions incoming facts of type TRightFact into dynamic key buckets without requiring an upstream left-hand Token anchor.

Template Parameters
TInitialThe initial fact type associated with the rule chain.
TRightFactThe type of fact being partitioned and aggregated.
TKeyThe non-nullable type of the grouping key.
Type Constraints
TKey :notnull
