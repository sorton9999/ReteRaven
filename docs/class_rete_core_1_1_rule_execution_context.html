Detailed Description

Provides an activation-scoped buffer for staged fact changes. The changes are not applied to the fact base until the context is completed, and can be discarded if the rule execution is aborted. An origin is stored with each change to identify the rule execution that produced it. The context also allows for controlled publication of the staged changes.
